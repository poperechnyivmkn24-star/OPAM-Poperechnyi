# Лабораторна 2 · Алгоритми обробки масивів

Василь Поперечний. Для запуску виконайте `dotnet run -c Release` з .NET 10 SDK.

1. `Describe` за один прохід рахує суму, середнє, кількість нулів та індекси перших мінімуму й максимуму.
2. `Filter` спочатку визначає розмір результату й за другий прохід записує всі кратні 5.
3. `LongestRun` оновлює довжину поточної серії на кожному кроці. За рівності зберігає першу найдовшу.
4. `SwapHalves` міняє рівні половини за допомогою обмінів. У масиві непарної довжини центральний елемент лишається на місці.
5. `AnalyzeMatrix` повертає суми рядків, максимуми стовпців та перший індекс рядка з найбільшою сумою. Індекси відлічуються з нуля.

| Вхід | Завдання | Очікувано | Отримано |
| --- | --- | --- | --- |
| [] | 1–4 | Немає статистики й серії, відбір і перестановка порожні | Немає статистики й серії, [], [] |
| [5] | 1–4 | Сума 5, середнє 5, обидва екстремуми 5 на індексі 0, нулів 0, відбір [5], серія (5, 1, 0), перестановка [5] | Усі значення збіглися |
| [2, 2, 2] | 1, 3 | Сума 6, середнє 2, екстремуми 2 на індексі 0, нулів 0, серія (2, 3, 0) | Усі значення збіглися |
| [2, 1, 1, 1] | 3 | Остання серія (1, 3, 1) | (1, 3, 1) |

Матриця дала суми рядків [−2, −1, 0, 1, 1, −1] і максимуми стовпців [0, 2, 3]. Перший рядок із максимальною сумою має індекс 3.
