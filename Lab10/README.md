## 4. Стрижень 33 см
- Оптимум жадібного алгоритму: 72/100.
- Найгірше відставання від максимальної використаної довжини: 21,21%.
- Найменший знайдений контрприклад за числом деталей: [12, 6, 5, 15, 14].
- Використана довжина для нього: жадібно 29 см, оптимально 33 см.
- 15 деталей: без відсікання 65535 вузлів, 0,1458 мс. З відсіканням 111 вузлів, 0,0007 мс.

## 5. Вибір алгоритму
1. На вході 50 000 символів прози, з яких виділено 7843 слів.
2. Запит один: повернути 8 найчастіших слів. Під час одного вимірювання текст незмінний.
3. Новий фрагмент потребує нового підрахунку. Для повторних запитів до того самого тексту можна кешувати частоти.
4. Для 50 000 символів словник виграв у часі в 36,21 раза. Словник витрачає пам’ять на записи частот, а наївний спосіб багато разів перечитує слова.
5. Dictionary і Array.Sort забезпечують зберігання та впорядкування. Токенізація й правила нічиєї залишаються частиною задачі.
6. На 1 000 символів отримано 0,1313 проти 0,0594 мс, на 50 000 — 72,9703 проти 2,0151 мс. Для повного фрагмента обираю словник.
