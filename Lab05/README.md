# Лабораторна 5 · Алгоритми на стеку та черзі

Індекси дужок нульові. Для незакритих дужок програма повертає індекс найранішої дужки, що залишилася в стеку.

Власний та стандартний стек дали однакові результати. На початку місткість дорівнює 5. Після кожного Push пари Count/Capacity були 1/5, 2/5, 3/5, 4/5, 5/5, 6/10. Pop на порожньому стеку дав очікуваний виняток «Стек порожній».

Черга обробила 11 заявок за 49 хвилин із квантом 2 хвилини. Максимальна довжина черги дорівнювала 11. Для порожнього входу вона дорівнювала 0.

Для дужок потрібен порядок LIFO, бо закривальна дужка відповідає останній ще відкритій. Черга спершу видала б зовнішню дужку й помилково відхилила вкладені пари. У зворотному польському записі два останні результати стають операндами нової операції. Якщо брати найстаріші результати, складні вирази та порядок віднімання можуть змінитися. Для заявок потрібен FIFO, щоб незавершена заявка після кванта чекала за іншими. Стек знову б узяв щойно повернуту заявку.

У №4 додавання 100 000 елементів у кінець зайняло 0,9147 мс, а вставка на початок 324,2686 мс. Це показує ціну зсуву елементів у List. Queue.Dequeue змінює індекс голови кільцевого буфера, а List.RemoveAt(0) зсуває весь хвіст.
